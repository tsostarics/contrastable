# Get contrast scheme labels for glimpse table

Looks up contrast functions from formulas and appends the necessary
namespaces

## Usage

``` r
.get_scheme_labels(list_params, formulas)
```

## Arguments

- list_params:

  List of params, see
  [`.make_parameters()`](https://tsostarics.github.io/contrastable/reference/dot-make_parameters.md)

- formulas:

  Formulas passed by the user

## Value

Character vector
